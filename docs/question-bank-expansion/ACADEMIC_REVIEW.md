## Socratic progression

All 84 records reuse exactly one question per letter. A asks for givens and goal, B for a method, C for justification, D for execution, E for interpretation and F for verification. The adapter uses A twice in seven internal phases and schedules verification before interpretation. Repetition is especially noticeable when the same A prompt is used for both the goal and the givens. D, E and F also repeat generic expected-evidence wording across very different tasks. B and C evidence often contains the theorem, intermediate calculation or complete answer. Keep that evidence private.

The sequence supports independent method choice when the statement leaves a real choice. For a proof, replace a generic D prompt with a question about the missing implication. For a probability tree, ask which events share a branch. For a decision problem, ask which choice can depend on the observation. Ask for one concrete independent check in F. Use corrective prompts after the corresponding error, with the weakest useful hint first. This review addresses authored guidance. The active AI tutor also bounds its dialogue by application stages, so faculty should review sample learner interactions after staging.
